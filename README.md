# Real-Time Object Detection Using YOLOv8 and OpenCV

## About the Project
This project detects and identifies multiple objects in real time using YOLOv8 and OpenCV.

It can detect objects such as:
- Person
- Car
- Bike
- Bus
- Dog
- Cat
- Mobile Phone

## Technologies Used
- Python
- YOLOv8
- OpenCV
- Ultralytics
- VS Code

## Features
- Real-time object detection
- Object identification
- Bounding box visualization
- Confidence score display
- Video processing using OpenCV

## Installation

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder:

```bash
cd Real-Time-Object-Detection-YOLOv8
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python main.py
```

## Output
The system displays detected objects with bounding boxes, object labels and confidence scores.
